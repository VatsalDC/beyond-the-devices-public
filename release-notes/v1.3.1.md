# Beyond the Devices for Mac — 1.3.1

Released 27 November 2026 · [Download page](https://beyondthedevices.com/download) ·
[Security architecture](https://beyondthedevices.com/security)

## What's new

- **Security Setup appears only when it is needed.** A normal update reuses the
  existing TLS identity, so the app no longer promises a Keychain prompt that
  macOS will not show. The explanation still appears before a fresh install or a
  repair that has to create the key.
- **Steadier file browsing.** Changing folders no longer cancels an in-flight
  download or video stream, and switching Macs clears stale requests instead of
  leaving them hanging.
- **Notifications remember what you have read.** Re-posting the same alert keeps
  its read state, changed content becomes unread, and the badge clears when you
  open the notifications inspector.
- **Hardened local media.** The stream server binds to loopback and checks
  content types, and the media adapter cleans up if its helper exits.
- **More reliable cleanup.** Bounded history and fewer stuck states after a
  dropped connection or a cancelled transfer.

The Mac app remains free.

## Requirements

- macOS 14 Sonoma or later, Apple Silicon (arm64)
- Android 8.0 or later, both devices on the same local network
