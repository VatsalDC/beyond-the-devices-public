# Beyond the Devices for Mac — 1.3.0

Released 22 November 2026 · [Download page](https://beyondthedevices.com/download) ·
[Security architecture](https://beyondthedevices.com/security)

## What's new

- **Home-screen widgets.** Battery rings for your phone and Mac, a Mac battery
  bar, a Command Center for sync and playback, and Now Playing.
- **Widgets follow the battery level in colour.** Green when charging or
  healthy, yellow in the middle, orange when low, red when critical.
- **Every widget has its own appearance.** Long-press a widget to set its
  opacity, from fully solid to fully clear, independently of the others.
- **Charging detection is smarter.** Charging is now detected whenever the Mac
  is on power, not only while the battery is actively filling, so a Mac holding
  at 80% on the charger reads as charging.
- **One-time Security Setup screen.** Before macOS asks for your login keychain
  password on first launch, the app now explains what the prompt is for: the
  app's own local TLS certificate, never your saved passwords.

## Requirements

- macOS 14 Sonoma or later, Apple Silicon (arm64)
- Android 8.0 or later, both devices on the same local network
