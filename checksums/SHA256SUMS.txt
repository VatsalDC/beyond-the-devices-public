# SHA-256 checksums

One line per published macOS disk image, newest first. The same digests appear
on the [download page](https://beyondthedevices.com/download) and on each GitHub
release.

Verify a download:

```sh
shasum -a 256 ~/Downloads/BeyondTheDevices-1.3.1.dmg
```
